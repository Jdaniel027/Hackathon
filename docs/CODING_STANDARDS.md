# Convenciones de código

- TypeScript estricto; no usar `any` salvo excepción aprobada y documentada.
- Componentes funcionales de React; nombres de componentes en PascalCase.
- Variables y funciones en camelCase; archivos consistentes con el repositorio.
- Preferir funciones pequeñas y responsabilidades únicas.
- Usar alias `@/` si está configurado.
- Tipar props, payloads y respuestas de API.
- No instalar paquetes para resolver tareas triviales.
- Evitar comentarios redundantes y logs de depuración en entregables.
- Manejar estados de carga, error y vacío en flujos asincrónicos.
- No cambiar estilos de archivos no relacionados.
- Antes de cerrar: lint, typecheck y build cuando corresponda.
