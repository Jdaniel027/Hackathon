# Sistema de diseño

> Valores provisionales; aprobarlos con el equipo al conocer el reto.

## Principios
- Claridad, consistencia, accesibilidad y diseño responsive.
- Usar Tailwind y tokens CSS; evitar valores arbitrarios dispersos.
- No introducir una segunda librería de componentes sin aprobación.

## Tokens por definir
- Primario: PENDIENTE.
- Fondo: PENDIENTE.
- Texto: PENDIENTE.
- Éxito / advertencia / error: PENDIENTE.
- Tipografía: PENDIENTE.
- Radio de borde y escala de espaciado: PENDIENTE.

## Componentes y estados
- Preferir componentes existentes de `components/ui/`.
- Toda vista con datos debe contemplar loading, vacío, error y éxito.
- Formularios con labels, validación y mensajes legibles.
- Navegación con estados activos y foco visible.
- Diseñar primero para móvil y adaptar a escritorio.

## Regla de consistencia
No cambiar colores, fuentes, tamaños ni patrones de navegación por criterio individual del agente. Solicitar aprobación y actualizar tokens centralizados.
