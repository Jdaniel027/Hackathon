# SARI: Sistema de Alerta y Reporte de Inundaciones

Una plataforma predictiva y de reporte ciudadano (PWA) para mapear, analizar y prevenir riesgos de inundación urbana en tiempo real. 

## El Problema
Las cuadrículas meteorológicas globales indican cuánto llueve, pero no cómo la topografía local y la infraestructura urbana (alcantarillas tapadas, desniveles en las calles) reaccionan a esa precipitación específica. Las alertas oficiales suelen ser demasiado generales y no previenen el daño a nivel de colonia o cuadra.

## La Solución
AquaReport combina **data macro** (precipitación meteorológica y elevación topográfica) con **data micro** (reportes ciudadanos geolocalizados). Si la API indica 30mm de lluvia por hora y la topografía señala una depresión en el terreno, el sistema advierte el riesgo de forma predictiva. Los reportes ciudadanos en el mapa validan la emergencia en tiempo real para el resto de la comunidad.
